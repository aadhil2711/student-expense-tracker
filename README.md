
# Student Expense Tracker

A simple and responsive web application that helps college students
manage their monthly budget and track daily expenses.

## Features

- Set and manage a monthly budget
- Add expenses with descriptions, categories, amounts, and dates
- Calculate total expenses and remaining balance
- View expense history
- Filter expenses by category
- Delete expense records
- Save data using browser LocalStorage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Set your monthly budget and start adding expenses.

## Project Purpose

This project was developed to help students monitor spending habits,
manage budgets, and improve financial awareness.

## Storage

Expense data is stored locally in the browser. It is not synchronized
between devices and does not use a server or database.
